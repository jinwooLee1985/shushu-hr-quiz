# 슈슈봇 인사퀴즈 문제은행

카카오톡 메신저봇(슈슈봇)이 평일 09~18시 매시 정각에 내는 인사·노무 퀴즈의 문제은행입니다.

- `quiz_bank.json` — 문제 목록. 봇이 3시간마다 내려받습니다.
- `bot/hr_quiz.js` — 메신저봇 스크립트 (최신본)
- `validate.js` — 문제은행 검증기 (`node validate.js`)
- `UPDATE_GUIDE.md` — 매주 업데이트 규칙
- `CHANGELOG.md` — 변경 이력

## 동작
- 출제 문제 중 약 35%는 봇이 법정 공식(연차·퇴직금·주휴수당·연장/야간수당·휴업수당·월 최저임금)으로 자동 생성합니다.
- 나머지는 이 문제은행에서 고르며, 최근 20문제는 다시 내지 않습니다.
- 인터넷 연결이 안 되면 마지막으로 받은 문제은행(없으면 봇 내장 52문제)으로 출제합니다.
- 정답자·답변 기록은 이 저장소가 아니라 **봇 폰에만** 저장됩니다 (`/sdcard/msgbot/quiz/`).

## 주의
문제와 해설은 일반적인 법령 정보이며 개별 사안에 대한 법률 자문이 아닙니다.
각 문제의 `checked`(검증일) 이후 법령이 바뀌었을 수 있습니다.
